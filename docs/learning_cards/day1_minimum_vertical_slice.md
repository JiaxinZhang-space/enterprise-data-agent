# 学习卡片：最小纵向闭环

## 需要能向面试官解释

最小纵向闭环不是先建完所有目录，而是让一条真实问题从输入走到可验证结果。本项目先把“2026 年 9 月 A 场错配率及环比”路由到 Metrics Tool；Tool 使用固定 SQL 模板和参数绑定，只统计 `status='valid'`，错配率按汇总后的分子/分母计算。这样先建立业务正确性基线，后续 LangGraph、PostgreSQL、RAG 和自由 SQL 都能与它对照。

## 面试追问及简答

问：为什么不用 LLM 直接生成这个 SQL？

答：高频、口径稳定的核心指标更适合确定性编译。它能控制粒度、过滤条件、空分母和允许维度，减少模型改写口径的风险；长尾复杂问题再交给受约束 SQL Tool。

## 5～15 分钟小练习

手算种子数据中 A 场 8 月和 9 月的错配率，说明为什么 8 月那条 `invalid` 事件不能进入分母；再把“提高 15%”改写成准确说法“提高 15 个百分点”。
