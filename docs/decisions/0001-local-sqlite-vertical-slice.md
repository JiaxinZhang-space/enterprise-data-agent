# ADR-0001：先用 SQLite 建立确定性纵向切片

- 日期：2026-10-10
- 状态：已采用，后续需复核

## 决策

Day 1 使用 Python 标准库、SQLite、规则路由和固定 Metrics SQL，先验证输入、路由、口径、只读查询、引用和拒绝输出。暂不接入 LangGraph、模型 API 或向量库。

## 原因

Docker 引擎未运行，且 Python 第三方依赖尚未安装。SQLite 是交接文档明确允许的快速闭环方案。固定 Metrics SQL 能先形成“业务正确性基线”，后续自由 Text-to-SQL 必须与它对照，而不能把 SQL 可执行误当作业务正确。

## 后果

- 优点：无外部服务、结果稳定、测试快、容易定位错误。
- 限制：当前路由不是 LangGraph；知识检索不是向量 RAG；意图级危险词拦截不是完整 SQL 安全。
- 迁移：Day 2～3 保持 `answer_question` 接口，替换传输层和数据库适配层。
